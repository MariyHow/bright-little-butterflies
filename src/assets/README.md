# Logo Assets

Place your logo file here:

- **`logo.png`** — Full logo (lightbulb + butterflies + "Bright Little Butterflies LLC Home Day Care")
  - Recommended: transparent background PNG, at least 400px wide

The logo is referenced in `src/components/Navbar.jsx` as:
```jsx
import logo from '../assets/logo.png'
```

Until you add the real file, the navbar will show the text name as a fallback.
